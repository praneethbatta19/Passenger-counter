# 🚏 Passenger Counter App

🔗 **Live Demo:** https://enchanting-praline-86a304.netlify.app/

A simple and interactive counter app built using **HTML, CSS, and
JavaScript** to track the number of passengers.\
This project was created to practice DOM manipulation and build a
responsive user interface.

------------------------------------------------------------------------

## 🛠️ Features

-   👍 Increment passenger count\
-   💾 Save the current count\
-   🧠 Beginner-friendly and lightweight\
-   📱 Works in all modern browsers

------------------------------------------------------------------------

## 📁 Project Structure

-   `index.html` -- Main HTML file\
-   `index.css` -- Styling and layout\
-   `index.js` -- Counter logic and DOM manipulation\
-   `station.jpg` -- Background image

------------------------------------------------------------------------

## 🚀 How to Run Locally

1.  Clone the repository:

    ``` bash
    git clone https://github.com/praneethbatta19/Passenger-counter.git
    ```

2.  Open the project folder.

3.  Open `index.html` in your browser.

No additional setup or build tools are required.
